## 💡 특이 케이스 분석

### 케이스 6: 띄어쓰기 변이 처리
- 입력: `"내방으로 와"` → STT 출력: `"내 방으로 와"`
- **공백 유무에 관계없이 매칭되도록 파서 예외 처리 적용** → 정상 파싱

### 케이스 7: 부정어 + 복합 명령 처리
- 입력: `"거실 말고 안방 가습기 편하게 켜줄래"`
- 부정어(`말고`) 이후의 대상(`안방`)만 정확히 타겟팅 → 정상 파싱

### 케이스 9: STT 오인식에도 파서 복원
- 입력: `"보일러 켜"` → STT 출력: `"보일락 켜"` (약간의 음성 인식 오류)
- **stt_parser.py의 키워드 매핑 로직이 `보일락` → `보일러`로 흡수** → 정상 파싱
