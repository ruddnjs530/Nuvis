# Error Codes (MVP)

|Code|Name|Description|
|---|---|---|
|0|OK|No error|
|1001|VALIDATION_FAILED|Task request rejected by validation|
|2001|NAVIGATION_FAILED|Navigation or return-home failed|
|3001|MODULE_FAILED|Module service execution failed|
|4001|CANCELED|Task canceled by user/system|
|5001|EMERGENCY_STOP|Emergency stop triggered|
|5002|LOW_BATTERY|Battery threshold event|
|6001|LOCALIZATION_LOST|Localization score below threshold|
