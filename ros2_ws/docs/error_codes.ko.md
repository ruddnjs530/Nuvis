# 오류 코드 (MVP)

|Code|Name|설명|
|---|---|---|
|0|OK|오류 없음|
|1001|VALIDATION_FAILED|검증 단계에서 작업 요청이 거절됨|
|2001|NAVIGATION_FAILED|이동 또는 복귀에 실패함|
|3001|MODULE_FAILED|모듈 서비스 실행에 실패함|
|4001|CANCELED|사용자/시스템 요청으로 작업이 취소됨|
|5001|EMERGENCY_STOP|긴급 정지가 트리거됨|
|5002|LOW_BATTERY|배터리 임계치 이벤트 발생|
|6001|LOCALIZATION_LOST|위치추정 신뢰도가 임계치 아래로 하락함|
